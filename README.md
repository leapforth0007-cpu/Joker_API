# Joke Hub

## About the Project
Joke Hub is a website where users can find and enjoy different jokes.

## Features
- Choose joke categories.
- Search jokes by keyword.
- Choose the number of jokes.
- Select joke formats.
- Show safe jokes only.

## Technologies Used
- HTML
- CSS
- JavaScript
- JokeAPI

## How to Run
1. Open the project in VS Code.
2. Open `index.html` in a browser.
3. Choose your options.
4. Click **Find Jokes** to see jokes.

## Goal
Our goal is to make a simple and fun joke website.
