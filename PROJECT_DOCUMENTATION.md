# Project Documentation

## Project Overview

Joke Hub is a joke generator website that uses JokeAPI to find and display different types of jokes. Users can choose joke categories, select the number of jokes, choose a joke format, search using keywords, and show safe jokes. The main objective is to create a simple and user-friendly website where people can find jokes for entertainment.
